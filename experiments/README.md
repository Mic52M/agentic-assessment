# experiments/

Archived assessment campaigns, kept under version control for reproducibility
and for citation in any later paper.

This directory is **tracked** in git, in contrast to `assessment_runs/` which
is gitignored as a working / transient directory. Move a campaign here once
you decide it's worth preserving.

## Naming convention

```
YYYY-MM-DD-<short-label>/
```

The label describes what was being tested, not when. Use kebab-case, keep
it short (≤ 30 chars). Examples:

- `2026-06-08-haiku-4-5-smoke` — first live smoke test on Haiku 4.5
- `2026-06-15-cross-model-baseline` — Opus vs Sonnet vs Haiku, baseline only
- `2026-07-02-l3-tool-loop-pilot` — first pilot of agency level L3

## Contents of each subdirectory

| File | What it is |
| --- | --- |
| `campaign.json` | Metadata: timestamp, label, model, seeds, limit, oracle, bootstrap config, command line. Auto-generated by `assessment.run`. |
| `results.json` | Raw `ExperimentResult` rows for every (ticket × seed × condition). |
| `metrics.json` | `metrics` block (per-metric value + 95% CI + n) and `comparisons` block (paired permutation tests). |
| `report.html` | Self-contained HTML report — open directly in a browser. |
| `runs/` | One JSON file per orchestrator run, with the full trace (state per node, tool calls, LLM calls with cost). Named `<condition>-<ticket_id>-s<seed>.json`. |

## Reproducing an archived campaign

Each `campaign.json` records the exact command line. Re-running it on the
same code revision should produce bit-identical content for everything
except wall-clock timestamps and per-call latencies (the LLM is
stochastic; the harness is not). For the *fully* reproducible case, run
with `--offline`: same seed ⇒ identical trace modulo timestamps.

## Adding a new campaign

```bash
# auto-labelled with timestamp
python -m assessment.run

# with an explicit label (recommended for archived campaigns)
python -m assessment.run --label cross-model-baseline

# then move the result into experiments/ once you confirm it's worth keeping
mv assessment_runs/2026-06-08-cross-model-baseline experiments/
```
